HOW TO DELETE:

OPTION 1: File Explorer (Easiest)
─────────────────────────────────────
1. Open: C:\Users\Son\Documents\CCM_Tool\CCM_Tool_v0.54.1
2. Sort by filename or use Ctrl+F to search "MCE_"
3. Select all files starting with "MCE_CCM"
4. Press Delete (or Shift+Delete for permanent removal)
5. If prompted "file in use":
   - Close ArcGIS, Python IDE, Command Prompt
   - Retry the delete

OPTION 2: Command Prompt (Administrator)
──────────────────────────────────────────
1. Win + R, type: cmd
2. Right-click → Run as Administrator
3. Navigate: cd C:\Users\Son\Documents\CCM_Tool\CCM_Tool_v0.54.1
4. Delete with wildcards:

   del MCE_CCM*.*

   (Or delete individually if needed:)
   del "MCE_CCM_v0.53.3.pyt"
   del "MCE_CCM_v0.54.0.pyt"
   etc.

OPTION 3: PowerShell
──────────────────────
1. Win + X, select "Windows PowerShell (Admin)"
2. Navigate: cd C:\Users\Son\Documents\CCM_Tool\CCM_Tool_v0.54.1
3. Remove:
   Get-ChildItem MCE_CCM* | Remove-Item -Force
