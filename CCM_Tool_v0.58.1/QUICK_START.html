CCM Tool v0.58.1

Integrated ArcGIS Pro toolbox + auto-selection recommendations

Operator quick start

New in v0.58.1

Step 0b now scores datasets on Quality (8 metrics), Fitness (role-specific), and Confidence, then recommends the best source for each role (DEM, Soil, Vegetation, etc.). You review and accept or override in Step 1.

What stays stable

v0.57 factual inventory + all Steps 0-4 mobility models unchanged. v0.58.1 adds scoring + recommendations; existing workflows work as before.

Recommendation workflow

Step 0b scores all datasets → generates recommendations → Step 1 displays them → you accept or choose an alternative → proceed to Steps 2-4.

1. Prepare and verify

Open Anaconda Prompt, change to the CCM_Tool_v0.58.1 folder, then run:

CCM_anaconda.bat
RUN_V058_TESTS.bat

The default environment is ccm_tool (Python 3.11, pytest, pyflakes, PyInstaller). CCM_anaconda.bat also runs conda activate for you, so this Anaconda Prompt is left inside ccm_tool when it finishes — no separate activation step needed.

For GeoPackage/file-geodatabase layer enumeration, install optional GDAL/OGR:

CCM_anaconda.bat ccm_tool_gdal --with-gdal
set CCM_ENV_NAME=ccm_tool_gdal
RUN_V058_TESTS.bat

2. Add the toolbox

  1. Open ArcGIS Pro and a project.
  2. Catalog pane → right-click Toolboxes → Add Toolbox.
  3. Select CCM_Tool_v0.58.1.pyt.
  4. Confirm six entries: Step 0, Step 0b, Step 1, Step 2, Step 3, and Step 4.

3. Recommended first run (v0.58.1 workflow)

Step 0Optional MGCP consolidation into a project geodatabase.
Step 0bScan data root; scores and auto-selects best sources per role.
Step 1Review recommendations; accept or override; preprocess inputs.
Steps 2-4Generate mobility maps and run analyses.
Step 0b outputs (v0.58.1): ccm_data_catalog.json, CCM_Data_Intelligence_Report.html (factual inventory), CCM_Recommendations_Report.html (NEW: auto-selection), ccm_quality_scores.json, ccm_fitness_scores.json, ccm_confidence_scores.json, ccm_recommendations.json (machine-readable).

4. Standalone scan options

Use the logged command-line launcher for a real data root:

RUN_DATA_SCAN.bat "D:\GIS\Source_Data" "D:\GIS\Project" "D:\GIS\Source_Data\Extent\AOI.shp"

Or launch the safe standalone GUI:

CCM_Data_Scanner.bat

5. ArcPy smoke test

ArcPy requirement: ArcPy comes from a licensed ArcGIS Pro installation. Open and sign in to ArcGIS Pro before running the test.
RUN_ARCGIS_SMOKE_TEST.bat

The script writes test data only below verification_artifacts and checks ArcPy metadata, container enumeration, report outputs, and source-data safety. The log is saved under verification_logs.
