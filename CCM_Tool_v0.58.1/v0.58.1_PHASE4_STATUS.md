## Version Management

### Version Bump Script

**File:** `bump_version.py` (v0.57 post-release "5.1")

Automates version updates across all project files:

**Features:**
- Pre-bump verification (package integrity check before bump)
- VERSION constant updates (all Python modules)
- Toolbox file rename (CCM_Tool_v*.pyt)
- Sidecar file renames (.pyt.xml, manual.docx)
- Post-bump verification (confirm package integrity after bump)
- Checksums and logging

**Usage:**
```bash
python bump_version.py 0.59
```

**What it updates:**
1. ccm_version.py VERSION constant
2. All module VERSION strings
3. Toolbox toolversion field
4. .pyt, .pyt.xml, and manual.docx filenames
5. Configuration file references

## Release Packaging

### Release Package Creator

**File:** `create_release_package.py`

Bundles project into verified release ZIP:

**Features:**
- Collects all project files matching include patterns
- Excludes temporary/cache files
- Creates ZIP with directory prefix (CCM_Tool_v0.58.1/*)
- Computes SHA256 checksum
- Generates manifest listing all files
- Verifies ZIP integrity
- Creates checksumsum file for distribution

**Usage:**
```bash
python create_release_package.py --version 0.58 --output-dir releases/
```

**Output Files:**
1. `CCM_Tool_v0.58.1.zip` — Compressed release package
2. `CCM_Tool_v0.58.1.sha256` — Integrity checksum
3. `release_manifest_v0.58.1.txt` — File listing and summary

**Verification:**
```bash
# Verify checksum
sha256sum -c CCM_Tool_v0.58.1.sha256
```
